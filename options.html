Two settings that matter for patch/mailing-list mail live in Thunderbird's Config Editor rather than its normal preferences. Thunderbird only lets extensions read them, not change them, so use the kernel.org guide to change them there if the badge below flags a problem. Copy the preference name into the Config Editor's search field to find it.

Flowed plain text output: –

mailnews.send_plaintext_flowed

Outgoing line length limit: –

mailnews.wraplength
